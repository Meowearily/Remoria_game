# Stage 1: Persistence & Currency System - Summary (LOOT_DEATH)

## Что было сделано:
В рамках первого этапа реализации мета-прогрессии были заложены фундаменты системы сохранения и управления валютой.

### 1. Система сохранения (`SaveManager.cs`)
Создан новый менеджер `SaveManager`, который отвечает за:
- Хранение данных игрока между сессиями в формате JSON (`remoria_save.json`).
- Автоматическую загрузку данных при запуске игры.
- Сохранение мета-валюты и уровней улучшений (здоровье, урон).
- Структуру данных `SaveData`, которую легко расширять в будущем для новых типов улучшений.

### 2. Система валюты (`CurrencyManager.cs`)
Создан `CurrencyManager` для управления "Осколками" (мета-валютой):
- **Текущий забег**: Отслеживает валюту, собранную игроком во время текущего прохождения.
- **Постоянная валюта**: Позволяет тратить накопленную валюту на улучшения.
- **Метод `FinalizeRun()`**: Обеспечивает перенос валюты из текущего забега в общее хранилище при смерти или завершении уровня.
- **События**: Добавлены Action-события для обновления UI при изменении количества валюты.

### 3. Подготовка к интеграции
- Оба менеджера используют паттерн `Singleton`, что позволяет обращаться к ним из любой части кода (например, из скрипта смерти врага).
- Файлы размещены в `Assets/Scripts/Core/` для соответствия архитектуре проекта.

## Как это работает сейчас:
1. При запуске игры `SaveManager` загружает существующий файл сохранения или создает новый.
2. `CurrencyManager` готов принимать валюту через `AddCurrency(int amount)`.
3. При вызове `FinalizeRun()` вся собранная за забег валюта прибавляется к общему счету и сохраняется на диск.
