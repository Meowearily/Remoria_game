# Stage 2.1: Game Over UI - Summary (LOOT_DEATH)

## Что было сделано:
В этом промежуточном этапе мы реализовали визуальную часть завершения игры.

### 1. Контроллер экрана смерти (`GameOverUI.cs`)
Создан новый скрипт для управления панелью Game Over:
- **Отображение результатов**: При появлении экран считывает количество собранных за забег осколков из `CurrencyManager` и выводит их в текстовое поле.
- **Кнопка "В Хаб"**: Загружает сцену Хаба (по умолчанию "HubScene") и восстанавливает скорость времени (`Time.timeScale = 1`).
- **Кнопка "Выход"**: Полностью закрывает приложение.

### 2. Изменение логики смерти (`PlayerDeath.cs`)
Мы немного изменили порядок действий при смерти:
1. Сначала активируется состояние `GameOver` в `GameManager`. Это нужно для того, чтобы UI успел прочитать значение "Валюты за забег", прежде чем она обнулится.
2. Только после этого вызывается `FinalizeRun()`, который сохраняет валюту и сбрасывает счетчик текущего забега.

## Как настроить в Unity:
1. В Hierarchy найди панель `GameOverPanel` (обычно она внутри Canvas).
2. Добавь на неё компонент **`GameOverUI`**.
3. Перетащи текстовое поле (TextMeshPro) в слот `Currency Collected Text`.
4. Перетащи соответствующие кнопки в слоты `Return To Hub Button` и `Quit Button`.
5. Убедись, что в поле `Hub Scene Name` вписано точное название твоей сцены с Хабом.
