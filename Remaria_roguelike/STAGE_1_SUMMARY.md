# Отчет о выполнении этапа 1: Подготовка данных и ScriptableObjects

В рамках первого этапа реализации новой системы процедурной генерации были созданы базовые структуры данных, которые позволят гибко настраивать уровни и фильтровать врагов без изменения кода в будущем.

## Созданные файлы

### 1. `Assets/Scripts/Enemy/EnemyDatabase.cs`
Это основной реестр всех врагов в игре.
*   **Функционал:** Разделяет врагов на три категории (Tier 1, Tier 2 и Boss).
*   **Параметры врага:** Каждая запись содержит ссылку на префаб и "Power Level" (стоимость сложности), что позволит системе балансировать количество врагов в комнате.
*   **Интеграция:** Добавлено меню `Create → Remoria → Enemy Database`.

### 2. `Assets/Scripts/World/LevelSettings.cs`
Конфигурационный файл для настройки параметров генерации конкретного этажа.
*   **Функционал:** Позволяет создавать отдельные ассеты настроек для Уровня 1 и Уровня 2.
*   **Настройки:** 
    *   Диапазон количества комнат (min/max).
    *   Размеры комнат в тайлах (3x3м).
    *   Веса для алгоритма A* (настройка сложности коридоров).
    *   Бюджет сложности врагов и шансы появления лута.
    *   Ссылки на визуальные префабы (плитки пола, стен и портала выхода).
*   **Интеграция:** Добавлено меню `Create → Remoria → Level Settings`.

## Инструкция по проверке в Unity

1.  **Создание базы врагов:**
    *   Нажмите правой кнопкой в папке `Assets/ScriptableObjects/Enemies`.
    *   Выберите `Create → Remoria → Enemy Database`.
    *   Заполните списки Tier 1 и Tier 2 существующими префабами врагов, назначив им числовой уровень силы (например, 10 для слабых, 30 для сильных).
    *   В поле `Final Boss Prefab` перетащите префаб босса.

2.  **Настройка параметров уровня:**
    *   Нажмите правой кнопкой в папке `Assets/ScriptableObjects/Rooms` (или создайте новую).
    *   Выберите `Create → Remoria → Level Settings`.
    *   Создайте два объекта: один для Floor 1, другой для Floor 2.
    *   Укажите соответствующие префабы пола (Floor) и стен (Wall). Убедитесь, что их физический размер соответствует сетке 3x3 метра.

3.  **Результат:**
    *   Теперь у нас есть централизованное место для управления балансом игры. Изменение количества врагов или размеров комнат теперь происходит через эти ассеты, а не через код.
