# Полное описание структуры файлов проекта Remaria Roguelike

Этот документ содержит подробное описание всех ключевых файлов и директорий проекта, включая скрипты, ассеты и конфигурации. Проект организован по модульному принципу в пространстве имен `Remoria`.

---

## 📂 Корневая директория (Документация и Конфигурация)

*   **`GEMINI.md`**: Основной файл инструкций для ИИ-ассистента и обзор архитектуры.
*   **`PROJECT_OVERVIEW_DETAILED.md`**: Детальное техническое описание всех систем игры.
*   **`FINAL_PROJECT_CHANGES.md`**: Итоговый отчет о последних крупных изменениях (Гибридная генерация, AI).
*   **`STAGE_1_SUMMARY.md`, `STAGE_2_SUMMARY.md`, `STAGE_3_SUMMARY.md`**: Промежуточные отчеты по этапам разработки.
*   **`Remaria_roguelike.sln`**: Файл решения Visual Studio для разработки на C#.

---

## 🛠 Скрипты (`Assets/Scripts/`)

### 核心 (Core) - Фундаментальные системы
*   **`GameManager.cs`**: Синглтон, управляющий состояниями игры (Игра, Пауза, Диалог, Конец игры).
*   **`LevelManager.cs`**: Управляет переходами между этажами и загрузкой сцен.
*   **`Health.cs`**: Система здоровья с событиями `OnHealthChanged` и `OnDied`.
*   **`IDamageable.cs`**: Интерфейс для всех объектов, которые могут получать урон.
*   **`Singleton.cs`**: Базовый класс для создания синглтонов.

### Мир и Генерация (World)
*   **`HybridLevelGenerator.cs`**: Новый основной генератор, сочетающий комнаты и A* коридоры.
*   **`DungeonGrid.cs`**: Логическая сетка уровня (тайлы, комнаты).
*   **`AStarPathfinder.cs`**: Алгоритм поиска пути для прокладки связных коридоров.
*   **`LevelSettings.cs`**: ScriptableObject с настройками генерации для конкретного этажа.
*   **`LevelGenerator.cs`**: Старая версия генератора (основанная на коннекторах).
*   **`RoomTemplate.cs` / `RoomDatabase.cs`**: Данные для старой системы генерации.
*   **`ExitPortal.cs`**: Логика перехода на следующий уровень при взаимодействии.

### Игрок (Player)
*   **`PlayerMovement.cs`**: Физическое передвижение, рывок (Dash) и поворот за камерой.
*   **`PlayerCombat.cs`**: Ближний бой, стрельба и система захвата цели (Lock-On).
*   **`PlayerInteraction.cs`**: Логика взаимодействия с объектами через Raycast.

### Искусственный интеллект (Enemy)
*   **`EnemyAI.cs`**: Основной мозг врага (FSM: Idle, Patrol, Chase, Attack).
*   **`EnemyController.cs`**: Управление физикой и анимациями врага.
*   **`EnemyDatabase.cs`**: Реестр типов врагов для генератора.
*   **`EnemyStats.cs`**: Данные о характеристиках конкретного врага.

### Боевая система (Combat)
*   **`Projectile.cs`**: Логика полета и попадания снаряда.
*   **`DamageInfo.cs`**: Структура данных для передачи информации об уроне.

### Диалоги и NPC
*   **`DialogueManager.cs`**: Контроллер выполнения диалогов.
*   **`DialogueData.cs`**: Структура данных диалога (текст, ветвление).
*   **`NPCController.cs`**: Логика поведения неигровых персонажей.

### Инвентарь (Inventory)
*   **`InventoryManager.cs`**: Хранение и использование предметов.
*   **`ItemData.cs`**: Описание свойств предмета (имя, иконка, эффект).
*   **`ItemPickup.cs`**: Логика подбора предмета в мире.

### Интерфейс (UI)
*   **`UIManager.cs`**: Главный контроллер всех окон интерфейса.
*   **`HealthBarUI.cs`**: Отображение здоровья игрока.
*   **`EnemyHealthBarUI.cs`**: Полоски здоровья над головами врагов.
*   **`DialogueUI.cs`**: Визуализация текста диалогов.
*   **`InventoryUI.cs` / `InventorySlotUI.cs`**: Интерфейс сумки игрока.
*   **`LevelTransitionUI.cs`**: Экраны загрузки и переходов между этажами.

## 📄 Данные (ScriptableObjects - `Assets/ScriptableObjects/`)

*   **`Dialogues/`**: Содержит ассеты диалогов (например, `ElderMira_Intro`).
*   **`Enemies/`**: Пресеты характеристик врагов (например, `Goblin_Stats`).
*   **`Items/`**: Данные о предметах (например, `HealthPotion`).
*   **`Rooms/`**: Настройки уровней (`SettingsFloor1`, `SettingsFloor2`).

---

## 📦 Ресурсы (Prefabs & Models)

*   **`Assets/Prefabs/`**: Готовые объекты для спавна (Player, Wall, Floor, Projectile, Portal).
*   **`Assets/Models/`**: 3D модели и анимации персонажей.
*   **`Assets/Materials/`**: Материалы и текстуры для окружения и сущностей.
